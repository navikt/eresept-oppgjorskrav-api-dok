# M23


Endepunkt for å hente utbetalingsresultat (M23) for et oppgjørskrav.

Flere oppgjør kan i teorien (muligens i en  nær fremtid) batches i en utbetaling.
En M23 kan derfor inneholde referanser til flere oppgjørskrav.
Pt. er det kun ett oppgjørskrav i en M23, og en endring av dette vil varsles.

Dersom behandling av oppgjøret resulterer i et null-oppgjør (kr 0 utbetalt) og oppgjøret ikke er avvist
vil oppgjørets status vises som Utbetalt når det er ferdig behandlet. Fordi det er et null-oppgjør vil det aldri
foretas en utbetaling, og et forsøk på å hente en M23 for dette oppgjøret vil resultere i http status 204.


| Felt                    | Verdi                       |
|-------------------------|-----------------------------|
| path                    | /oppgjorskrav/m23           |
| query string parameter  | `oppgjorsnr`: et oppgjorsnr |
| method                  | GET                         |
| content type            | application/xml             |



| Status | Response  | Forklaring                                        |
|--------|-----------|---------------------------------------------------|
| 200    | M23 (XML) | M23 er tilgjengelig og returneres                 |
| 204    |           | M23 er ikke produsert og ingen respons returneres |
| 400    |           | Oppgjøret finnes ikke                             |
| 451    |           | Direkteoppgjørsavtale er ikke på plass            |
